The Online Event Registration System is a web-based application designed to simplify and organize the process of managing event-related activities through a centralized digital platform. The project focuses on transforming conventional registration procedures into a more structured, accessible, and efficient system by integrating user interaction, event information, and administrative management.  The system provides an organized environment where users can explore available events, access relevant event details, submit registration requests, and retrieve their registration information. It also incorporates administrative functionalities that support event creation, modification, monitoring of registrations, and management of event-related records.  Developed using Python Flask, SQLite, HTML, CSS, and JavaScript, the application follows a modular approach that connects the user interface with server-side processing and database operations. The integration of these technologies enables systematic data handling, improved information accessibility, and streamlined communication between users and administrators.  The primary objective of this project is to demonstrate how web technologies can be applied to develop a centralized event management solution that reduces manual intervention, improves operational organization, and provides a consistent registration experience. The system represents a practical application of software development principles, database management, and web-based information systems
